# شجره‌نامه | نرم‌افزار حرفه‌ای مدیریت شجره‌نامه خانوادگی

نسخهٔ کامل و آماده برای انتشار روی **GitHub Pages**.

## امکانات

- ذخیره کامل در مرورگر (IndexedDB) — داده‌ها هیچ‌وقت گم نمی‌شوند
- PWA: قابل نصب روی موبایل و دسکتاپ + کار آفلاین
- آیکون اختصاصی
- شجره‌نامه نمونه «خانواده آزادگان» در اولین ورود (۱۷ نفر، چند نسل)
- درخت تعاملی با زوم، جابه‌جایی و خطوط روابط
- روابط: پدر، مادر، فرزند، همسر، همسر سابق، خواهر/برادر، فرزندخوانده
- Undo / Redo
- جستجو و فیلتر
- نمای درختی / لیستی / تایم‌لاین
- پنل جزئیات فرد + منوی راست‌کلیک
- آپلود عکس پروفایل
- آمار خانواده
- خروجی‌ها: PDF، PNG، HTML، JSON، GEDCOM
- ۵ تم رنگی
- پشتیبانی کامل فارسی و RTL

## انتشار روی GitHub Pages

1. یک ریپازیتوری جدید بساز
2. تمام محتوای پوشه `shajareh` را داخل root ریپازیتوری قرار بده
3. از **Settings → Pages** منبع را روی branch اصلی و پوشه root تنظیم کن
4. آدرس سایت:
   `https://YOUR_USERNAME.github.io/REPO_NAME/`

## اجرای محلی

```bash
cd shajareh
python -m http.server 8000
```

باز کن: http://localhost:8000

## نکات

- داده‌ها فقط روی دستگاه کاربر ذخیره می‌شود.
- اگر می‌خواهی از صفر شروع کنی: تنظیمات → پاک کردن تمام داده‌ها.

ساخته شده برای حفظ تاریخ خانواده.
