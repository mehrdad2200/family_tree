# Family Tree V2
نسخه دوم پروژه شجره‌نامه فارسی.

## امکانات افزوده
- بخش عکس و اسناد
- آماده‌سازی رابط Cloud و Google Login
- اشتراک‌گذاری پروژه
- Import/Export JSON
- خروجی GEDCOM
- نگهداری فایل‌های تصویری در LocalStorage
- ساختار مناسب برای اتصال Firebase/Supabase در مرحله بعد

## اجرا
فایل `index.html` را در مرورگر باز کنید.
برای GitHub Pages کافی است فایل‌ها را در repository قرار دهید.

## نکته Cloud
Google OAuth و دیتابیس آنلاین نیازمند ایجاد پروژه در Firebase/Supabase و تنظیم credentialهای واقعی است؛ این نسخه رابط و معماری پایه آن را آماده کرده است و بدون کلید شخص ثالث وانمود نمی‌کند که Cloud واقعی فعال است.
