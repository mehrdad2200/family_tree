# شجره‌نامه | Family Tree Manager

نرم‌افزار کامل و حرفه‌ای برای ساخت، مدیریت و خروجی گرفتن از شجره‌نامه خانوادگی.

## ویژگی‌ها

- **ساخت پروژه**: چندین شجره‌نامه جداگانه (مثلاً خانواده آزادگان، خانواده مادری و ...)
- **افراد**: اطلاعات کامل (نام، تاریخ تولد/فوت، محل، شغل، زندگینامه، درجه اطمینان)
- **روابط پیشرفته**: پدر، مادر، فرزند، همسر، خواهر/برادر
- **درخت تعاملی**: زوم، جابه‌جایی، انتخاب افراد، نمایش نسل‌ها
- **ذخیره دائمی**: IndexedDB (اطلاعات حتی بعد از بستن مرورگر باقی می‌ماند)
- **خروجی‌ها**:
  - PDF با کیفیت بالا
  - تصویر PNG
  - فایل HTML کامل و زیبا (قابل انتشار روی GitHub Pages)
  - پشتیبان JSON
- **ظاهر**: پشتیبانی کامل فارسی و RTL + فونت وزیرمتن + چند تم رنگی
- **بدون نیاز به سرور**: کاملاً سمت کاربر کار می‌کند

## نحوه استفاده

1. فایل‌ها را روی GitHub Pages یا هر هاست استاتیک آپلود کنید
2. یا به‌صورت محلی با یک سرور ساده اجرا کنید:

```bash
# با Python
python -m http.server 8000

# یا با Node
npx serve .
```

3. مرورگر را باز کنید: `http://localhost:8000`

## ساختار فایل‌ها

```
shajareh/
├── index.html          # صفحه اصلی
├── css/
│   └── style.css       # استایل کامل RTL
├── js/
│   ├── db.js           # لایه دیتابیس (IndexedDB)
│   ├── tree.js         # موتور نمایش درخت
│   ├── export.js       # خروجی PDF / PNG / HTML / JSON
│   └── app.js          # منطق اصلی برنامه
└── README.md
```

## انتشار روی GitHub Pages

1. یک ریپازیتوری جدید بسازید
2. محتوای پوشه `shajareh` را داخل آن قرار دهید
3. از Settings → Pages، منبع را روی `main` branch تنظیم کنید
4. آدرس سایت شما آماده است
