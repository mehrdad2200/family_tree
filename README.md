# شجره‌نامه | نرم‌افزار حرفه‌ای مدیریت شجره‌نامه خانوادگی

نسخهٔ پیشرفته و کامل برای ساخت، ویرایش، نمایش و خروجی گرفتن از شجره‌نامه خانوادگی.

## ویژگی‌های اصلی

- **پروژه‌های متعدد**: چندین شجره‌نامه جداگانه
- **افراد کامل**: نام، تاریخ تولد/فوت، محل، شغل، تحصیلات، زندگینامه، عکس، درجه اطمینان
- **روابط پیشرفته**: پدر، مادر، پسر، دختر، همسر، همسر سابق، برادر، خواهر، فرزندخوانده
- **موتور درخت حرفه‌ای**: لایه‌بندی نسل‌ها، خطوط والد-فرزند و همسر، زوم و جابه‌جایی
- **Undo / Redo**
- **جستجو و فیلتر** (جنسیت، زنده/فوت‌شده)
- **نمای درختی، لیستی و تایم‌لاین**
- **پنل جزئیات فرد (Inspector)**
- **منوی راست‌کلیک**
- **آمار خانواده**
- **خروجی‌ها**:
  - PDF درخت
  - PNG با کیفیت بالا
  - HTML کامل (قابل انتشار روی GitHub Pages)
  - JSON پشتیبان
  - GEDCOM (استاندارد جهانی)
- **تم‌های رنگی**: جنگلی، اقیانوسی، خاکی، سلطنتی، تیره
- **ذخیره دائمی** با IndexedDB
- **پشتیبانی کامل فارسی و RTL**

## نحوه اجرا

```bash
cd shajareh
python -m http.server 8000
```

سپس در مرورگر باز کنید: http://localhost:8000

یا روی GitHub Pages آپلود کنید.
